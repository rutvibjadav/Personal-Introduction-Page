# Personal Introduction Page

A responsive, single-page personal introduction website for **Rutvi Jadav**, created for the Veda Technology Web Development Internship, Day 2 Task 2.

## Features

- Introduction hero with a profile image area and About section link
- About, skills, hobbies, and contact sections
- Responsive layout for desktop, tablet, and mobile screens
- Hover and keyboard-focus states for navigation, buttons, and contact links
- Semantic HTML, accessible labels, and reduced-motion support
- Contact details are clearly marked as placeholders until you add your own

## Technologies

- HTML5
- CSS3

This project uses no JavaScript or external frameworks.

## Add your profile image

Place a portrait image named **`profile.jpg`** in the same folder as `index.html`. The page refers to it as `profile.jpg`. If the file is missing, a light-blue panel with the initials RJ and a reminder to add the image appears instead.

## Add your contact details

In `index.html`, replace the marked placeholders in the Contact section with your real details:

- Set the email link's `href` to `mailto:YOUR_EMAIL_ADDRESS` and replace its visible placeholder.
- Set the LinkedIn and GitHub `href` values to your own profile URLs and replace their visible placeholders.

The sample values in the HTML are deliberately labeled placeholders; replace them before sharing the page.

## Run the project

### Open in a browser

1. Open the project folder.
2. Double-click `index.html`, or right-click it and choose a browser.

### Run using VS Code

1. Open VS Code and choose **File → Open Folder...**.
2. Select the `Personal-Introduction-Page` folder.
3. Open `index.html` and choose **Open with Live Server** if you have the Live Server extension installed. Alternatively, open `index.html` directly in your browser.

No build or installation step is required.

## Share the project

### Upload to a public GitHub repository

1. Sign in to GitHub and create a new repository. Choose **Public** if you want anyone to view it.
2. Give it a name such as `personal-introduction-page`.
3. Upload `index.html`, `style.css`, `README.md`, and your own `profile.jpg` using GitHub's **Add file → Upload files** option, then commit the upload.
4. Check the repository page to confirm that the files are visible. This project is a static website and is not deployed by these steps.

### Share on LinkedIn

Once your repository is public, create a LinkedIn post describing the internship task and what you learned. Add the URL of your GitHub repository to the post. If you later choose to publish a live version, share that URL only after deployment is complete; no deployment is configured in this project.
